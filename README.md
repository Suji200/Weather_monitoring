# Weather_monitoring

set up and run the project on your local machine.

Prerequisites
Java (JDK 11 or higher)
Maven (or Gradle)
Postman or any API testing tool
An API key from a weather service provider

Technologies Used
Java Spring Boot for REST API
Maven for dependency management
Third-party Weather API
MongoDb DataBase

Future Improvements
Provide historical weather data.
Add authentication to the API.
